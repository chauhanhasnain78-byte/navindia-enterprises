# Product Illustrative Image Prompts — NAV INDIA ENTERPRISES

All product pages look up their illustrative image at `/public/products/<category>/<product>.webp`.
When an image file is not yet placed in `/public/products/<category>/`, the website automatically displays a neutral dark-navy gradient placeholder with a category icon and zero layout shift.

## Global Style Guidelines
- **Aspect Ratio:** `4:3` (e.g. `1200x900` or `800x600`, saved as `.webp`)
- **Background:** Neutral dark navy / slate grey studio backdrop (`#10233E` to `#1E3658`)
- **Composition:** Centred, product only, clean studio lighting, realistic metallic/rubber surface reflections, soft contact shadow
- **Strict Exclusions:** No brand names, no text, no part numbers, no logos, no watermarks, no human hands
